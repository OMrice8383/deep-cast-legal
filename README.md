# deep-cast-legal

DEEP Cast（iPhone アプリ）の公開用の法的文書だけを置く専用リポジトリです。
`customer-hub` のコード・資格情報・顧客情報は含みません。

## プライバシーポリシー

- 公開ページ：[DEEP Cast プライバシーポリシー](https://omrice8383.github.io/deep-cast-legal/legal/privacy-policy.html)
- リポジトリ内の文書：[docs/legal/privacy-policy.html](docs/legal/privacy-policy.html)

GitHub Pages は `main` ブランチの `docs/` を公開します。公開 URL には `docs/` を含めません。
